# نظام منح الدرجات والشهادات في الجامعة الالمانية الاردنية /صادر بمقتضى الفقرة (د) من المادة (25) من قانون الجامعات الاردنية الرسمية رقم (42) لسنة 2001

##### المادة 1

يسمى هذا النظام ( نظام منح الدرجـــات والشهادات في الجامعة الالمانيـــة الاردنية لسنـــة 2008 ) ويعمل به من تاريخ نشره في الجريدة الرسمية 0

##### المادة 2

يكون للكلمات التالية حيثما وردت في هذا النظام المعاني المخصصة لها ادناه مـا لم تدل القرينة على غير ذلك :-
الجامعــة : الجامعة الالمانية الاردنية 0
المجلس : مجلس عمداء الجامعة 0
الكليـة : أي كلية في الجامعة 0
المركز : أي مركز علمي في الجامعة 0
المعهد : أي معهد علمي في الجامعة 0

##### المادة 3

تمنح الجامعة ما يلي :-

أ-الدرجة الجامعية الاولى ( البكالوريوس ) 0

ب-الدرجة الجامعية الثانية ( الماجستير ) 0

ج-الدرجة الجامعية الثالثة ( الدكتوراة ) 0

د- درجة الدكتوراة الفخرية 0

هـ- أي درجة علمية او درجة فخرية او شهادات اخرى يوافق عليها المجلس 0

##### المادة 4

أ- تحدد متطلبات وشروط منح الدرجات العلمية والشهادات وحقول التخصص ذات العلاقة بها بمقتضى تعليمات يصدرها المجلس 0

ب- تحدد متطلبات وشروط منح الدرجات الفخرية بمقتضى تعليمات يصدرها المجلس 0

##### المادة 5

أ- تمنح الدرجات والشهادات من مستوى الدرجة الجامعيـة الاولى ( البكالوريوس ) بقرار من المجلس بناء على
تنسيب من مجلس الكلية المختص او مجلس المركز او المعهد المختص في الجامعة حسب مقتضى الحال 0

ب-تمنح الدرجات والشهادات من مستوى الدرجة الجامعيــة الثانية ( الماجستير ) والدرجة الجامعية الثالثة
(الدكتوراة) بقرار من المجلس بناء على تنسيب مجلس الدراسات العليا المستند الى توصية مجلس الكلية او
مجلس المركز او المعهد المختص في الجامعة 0

ج-تمنح الدرجات الفخرية بقرار من المجلس بناء على تنسيب رئيس الجامعة 0
