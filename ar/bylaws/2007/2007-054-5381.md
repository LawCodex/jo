# نظام التنظيم الاداري لتطوير القطاع العام

##### المادة1- يسمى هذا النظام ( نظام التنظيم الاداري لوزارة تطوير القطاع العام لسنة 2007 ) ويعمل به من

تاريخ نشره في الجريدة الرسمية 0

##### المادة2- يكون للكلمات والعبارات التالية حيثما وردت في هذا النظام المعاني المخصصة لها ادناه ما لم تدل

القرينة على غير ذلك :-
الوزارة:وزارة تطوير القطاع العام 0
الوزير:وزير تطوير القطاع العام 0
الامين العام:امين عام الوزارة 0
المديرية :أي مديرية في الوزارة 0
المدير:مدير المديرية 0
اللجنة:لجنة التخطيط المشكلة بموجب احكام هذا النظام 0

##### المادة3- تتولى الوزارة المهام والصلاحيات التالية

?أ-اعداد السياسات العامة لادارة وتنمية الموارد البشرية في القطاع العام ووضع الخطط والبرامج اللازمــــــة تنفيذها 0
?ب-العمل على تطوير الهياكل التنظيميه ووضع الخطط والبرامج اللازمة لذلك 0
?ج-تقديم الرأي حول انظمة التنظيم الاداري لدوائر ومؤسسات القطاع العام وتقديم المشورة لتطوير هياكلها
التنظيمية 0
?د-اعداد السياسات العامة المتعلقة بتطوير القطاع العام وتحسين ادائه والعمل على رفع مستوى الخدمات المقدمة
وتبسيط اجراءاتها 0

هـ- وضع اسس الاستخدام الامثل للموارد البشرية في القطاع العام ووضع الخطط والبرامج اللازمة لتنفيذها ،
ومتابعة تطبيق وصف الوظائف وتصنيفها 0
?و-المساهمة في اعداد سياسات واستراتيجيات التدريب وبناء القدرات في القطاع العام ، وتقديم الدعم والمشورة
لبناء قدرات مؤسسات القطاع العام في مجال ادارة الموارد البشرية واعادة هيكلة الخدمات الحكومية وتحسينها 0

ز- نشر ثقافة الابداع والتميز في القطاع العام وتكريسها.

ح- دعم آليات صنع القرار ورسم السياسات وتقديم الدعم الفني في عمليات التخطيط الاستراتيجي ومتابعة الاداء المؤسسي.
?ط-أي مهام اخرى يرى مجلس الوزراء او رئيس الوزراء تكليفها بها 0

##### المادة 4

‌أ- الامين العام 0

‌ج- مديرية السياسات وتنمية الموارد البشرية 0
‌د-مديرية اعادة الهيكلة 0

هـ- مديرية تطوير الخدمات وتبسيط الاجراءات 0

و- مديرية دعم الابداع والتميز الحكومي 0

ز- مديرية دعم السياسات وصنع القرار .

ح- مديرية الشؤون الادارية 0

ط- مديرية الشؤون المالية.

ي- وحدة الرقابة الداخلية 0

ك- وحدة الشؤون القانونية 0

ل- وحدة الاتصال والاعلام 0

م- وحدة متابعة المشاريع 0

2-المعهد الوطني للتدريب 0

3-وحدة الرقابة الداخلية 0

4- وحدة متابعة المشاريع.

5- مكتب الوزير 0

ب- يرتبط بالامين العام كل من :-

1- مساعد الامين العام 0

2- المديريات 0

3-وحدة الشؤون القانونية 0

4- وحدة الاتصال والاعلام.

##### المادة6-أ-تتم تسمية مديري المديريات ورؤساء الوحدات الادارية بقرار من الوزير بناء على تنسيب الامين العـــام 0

ب- تتم تسمية رؤساء الاقسام في المديريات بقرار من الامين العام 0

##### المادة7-أ- تشكل في الـــوزارة لجنـــــة تسمى ( لجنــــة التخطيط ) برئاسة الوزير وعضوية كل من

1-الامين العام ، نائباً للرئيس 0

2-مدير عام المعهد الوطني للتدريب 0

3- مساعد الامين العام0

4- مديري المديريات ورؤساء الوحدات0ب- تتولى اللجنة دراسة الامور المبينة ادناه ، ورفع توصياتها للوزير لاتخاذ الاجراءات اللازمة بشأنها :-

1- الخطط والبرامج والانشطة اللازمة لتنفيذ مهام الوزارة وتقييمها 0

2- مشروعات الانظمة والتعليمات المتعلقة بعمل الوزارة 0

3- مشروع الموازنة السنوية للوزارة وجدول تشكيلات الوظائف فيها 0

4- أي امور اخرى يحيلها الوزير اليها 0

ج- تجتمع اللجنة بدعوة من رئيسها او نائبه عند غيابه مرة على الاقل كل شهر وكلما دعت الحاجة ويكون
اجتماعها قانونياً بحضور ما لا يقل عن ثلثي اعضائها ، على ان يكون من بينهم الرئيس او نائبه ، وتتخذ توصياتها
بأكثرية اصوات اعضائها الحاضرين على الاقل 0

د- للوزير دعوة أي شخص من داخل الوزارة او خارجها لحضور اجتماع اللجنة للاستئناس برأيه في أي من الامور
المعروضة عليها 0

هـ- يسمي الوزير احد موظفي الوزارة اميناً لسر اللجنة يتولى حفظ قيودها وسجلاتها ومعاملاتها واعداد جدول
اجتماعاتها وتدوين محاضر جلساتها وتوصياتها 0

##### المادة8-أ- للوزير تشكيل أي لجنة دائمة او مؤقتة يتطلبها قيام الوزارة بمهامها ، على ان يحدد في قرار تشكيلها

مهامها وطريقة عملها 0

ب- للوزير الاستعانة بذوي الخبرة والاختصاص من خارج الوزارة للاستئناس بآرائهم ، ولمجلس الوزراء بناء على
تنسيب الوزير صرف مكافآت مالية لهم 0

##### المادة9- يصدر الوزير التعليمات اللازمة لتنفيذ احكام هذا النظام بما في ذلك ما يلي

?أ-تحديد مهام المديريات والوحدات والاقسام والواجبـات الموكولة لاي منها 0
?ب-وصف الوظائف في الوزارة 0
