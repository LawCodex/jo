# نظام تشكيل محكمة شرعية في قضاء العارضة صادر بمقتضى المادة (21) من قانون تشكيل المحاكم الشرعية رقم (19) لسنة 1972

##### المادة 1

يسمى هذا النظام ( نظام تشكيل محكمة شرعية في قضاء العارضة لسنة 2007 ) ويعمل به بعد ثلاثين يوماً من تاريخ نشره في الجريدة الرسمية 0

##### المادة 2

تشكل محكمة شرعية ابتدائية في قضاء العارضة ويكون مكان انعقادها في مركز القضاء ( الصبيحي ) 0

##### المادة 3

تشمل دائرة اختصاص المحكمة المناطق التالية :-

أ-الصبيحي 0

ب-بيوضه الشرقية 0

ج-سيحان 0

د-عليقون 0

هـ-بيوضه الغربية 0

و- بيوضه الشمالية 0

ز- خشفه 0

ح- جريش 0

ط- العزب 0

ي- قصيب 0

ك-البويب 0

ل-ميسرا 0

م-الحقاوه 0

ن-المنصورة 0

س-الضريسات 0

ع-عرقوب الراشد 0

ف- المزارع والعشائر والتجمعات السكانية والمناطق الادارية التابعة لها حسب نظام التقسيمات الادارية المعمول به 0

##### المادة 4

يلغى أي نص في أي تشريع آخر الى المدى الذي يتعارض فيه مع احكام هذا النظام 0
