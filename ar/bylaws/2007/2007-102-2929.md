# نظام تشكيل محكمة شرعية في قضاء الجفر صادر بمقتضى المادة(21) من قانون تشكيل المحاكم الشرعية رقم (19) لسنة 1972

##### المادة 1

يسمى هذا النظام ( نظام تشكيل محكمة شرعية في قضاء الجفر لسنة 2007 ) ويعمل به بعد ثلاثين يوماً من تاريخ نشره في الجريدة الرسمية 0

##### المادة 2

تشكل محكمة شرعية ابتدائية في قضاء الجفر ويكون مكان انعقادها في مركز القضاء ( الجفر ) 0

##### المادة 3

تشمل دائرة اختصاص المحكمة المناطق التالية :-

أ-الجفر 0

ب-المدورة 0

ج-الشيدية 0

د-باير 0

هـ-المشاش 0

و- الشهيباء 0

ز- كبيده 0

ح- العناب 0

ط- كبد 0

ي- سهب 0

ك- المزارع والعشائر والتجمعات السكانية والمناطق الادارية التابعة لها حسب نظام التقسيمات الادارية المعمول به 0

##### المادة 4

يلغى أي نص في أي تشريع آخر الى المدى الذي يتعارض فيه مع احكام هذا النظام 0
