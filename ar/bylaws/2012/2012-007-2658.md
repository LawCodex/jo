# نظام التنظيم الاداري لصندوق التنمية والتشغيل / صادر بمفتضى المادة (120) والمادة (17) من قانون صندوق التنمية والتشغيل (33) لسنة 1992

##### المادة 1

يسمى هذا النظام ( نظام التنظيم الاداري لصندوق التنمية والتشغيل لسنة 2012 ) ويعمل به من تاريخ نشره
في الجريدة الرسمية 0

##### المادة 2

يكون للكلمات التالية حيثما وردت في هذا النظام المعاني المخصصة لها ادناه ما لم تدل القرينة على غير ذلك :-
القانون :قانون صندوق التنمية والتشغيل النافذ 0
الصندوق :صندوق التنمية والتشغيل 0
المجلس :مجلس ادارة الصندوق0
الرئيس : رئيس المجلس0
المدير:مدير عام الصندوق0
اللجنة :لجنة التخطيط والتطوير 0

##### المادة 3

يتكون الهيكل التنظيمي للصندوق من :-

أ-المجلس 0

ب-المدير 0

ج-مساعدي المدير 0

د-مكتب المدير 0

هـ- المديريات التالية :-

1-مديرية التخطيط والتميز المؤسسي 0

2-مديرية الموارد البشرية والخدمات المساندة 0

3-مديرية التدريب والتمكين 0

4-مديرية الشؤون القانونية 0

5-مديرية المتابعة والتحصيل 0

6-مديرية الشؤون المالية 0

و- فروع الصندوق في المحافظات 0

ز- الوحدات التالية :-

1-وحدة الرقابة المالية والتدقيق الداخلي 0

2-وحدة العلاقات العامة والاعلام 0

3-وحدة تكنولوجيا المعلومات 0

##### المادة 4

يرتبط بالمدير كل من :-
?أ-مساعد المدير للشؤون المالية والموارد البشرية 0
?ب-مساعد المدير للشؤون الفنية 0
?ج-مساعد المدير لشؤون المحافظات 0
?د- مكتب المدير 0

هـ- مديرية الشؤون القانونية 0

و- وحدة الرقابة المالية والتدقيق الداخلي 0

ز- وحدة العلاقات العامة والاعلام 0

##### المادة 5

ترتبط بمساعــد المدير للشــؤون الماليــة والموارد البشرية المديريات التاليـــة :-
?أ-مديرية الموارد البشرية والخدمات المساندة 0
?ب-مديرية المتابعة والتحصيل 0
?ج-مديرية الشؤون المالية 0

##### المادة 6

ترتبط بمساعد المدير للشؤون الفنية المديريات التالية :-
?أ- مديرية التخطيط والتميز المؤسسي 0
?ب-مديرية التدريب والتمكين 0
?ج-وحدة تكنولوجيا المعلومات 0

##### المادة 7

ترتبط فروع الصندوق في المحافظات بمساعد المدير لشؤون المحافظات 0

##### المادة 8

أ- تشكل في الصندوق لجنة تسمى ( لجنة التخطيط والتطوير ) برئاسة المدير وعضوية كل من :-

1-مساعدي المدير 0

2-مديري المديريات 0

3-رؤساء الوحدات 0

ب- يتولى اقدم المساعدين رئاسة اللجنة في حال غياب المدير 0

##### المادة 9

أ- تتولى اللجنة دراسة الامور التالية وتقديم التوصيات اللازمة بشأنها:-

1-خطط وبرامج الصندوق وتنظيمها ومتابعة تنفيذها 0

2-مشروع الموازنة السنوية للصندوق وجدول تشكيلات الوظائف فيه 0

3-مشروعات القوانين والانظمة والتعليمات المتعلقة بعمل الصندوق 0

4-اي امور اخرى يحيلها الرئيس او المدير اليها 0

ب- تجتمع اللجنة بدعوة من رئيسها او من يقوم مقامه في حال غيابه مرة على الاقل كل ثلاثة اشهر ، وكلما دعت
الحاجة ، ويكون اجتماعها قانونياً بحضور اغلبية اعضائها ، على ان يكون المدير او من يقوم مقامه من بينهم وتتخذ
توصياتها بأغلبية اصوات اعضائها الحاضرين 0

ج- لرئيس اللجنة ، او من يقوم مقامه في حال غيابه ، دعوة اي من موظفي الصندوق او اي شخص من خارجه
للمشاركة في اجتماعات اللجنة للاستئناس برأيه في الامور المعروضة عليها دون ان يكون له حق التصويت 0

د- يسمي المدير احد موظفي الصندوق اميناً لسر اللجنة يتولى تنظيم جدول اعمالها وتدوين محاضر جلساتها
وحفظ قيودها ومعاملاتها ومتابعة تنفيذ توصياتها 0

##### المادة 10

أ- للمجلس بناء على تنسيب المدير المستند الى توصية اللجنة احداث اي مديرية او وحدة في الصندوق او
دمج اي من المديريات او الوحدات في غيرها 0

ب- للمدير بناء على تنسيب اللجنة احداث اي قسم او دمجه في غيــره 0

##### المادة 11

يصدر المجلس بناء على تنسيب المدير التعليمات اللازمة لتنفيذ احكام هذا النظام بما في ذلك ما يلي :-
أ?-مهام مساعدي المدير ومديري المديريات ورؤساء الوحدات الادارية 0
ب?-مهام المديريات والوحدات والاقسام ومسؤولياتها 0

ج- تحديد العلاقة واساليب الاتصال والتنسيق بين المديريات وسائر الوحدات الادارية في الصندوق 0
