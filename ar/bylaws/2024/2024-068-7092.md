# نظام مكافحة الحشرات والقوارض والزواحف وناقلات الأمراض ضمن حدود أمانة عمان

##### المادة 1

يسمى هذا النظام ( نظام مكافحة الحشرات والقوارض والزواحف وناقلات الأمراض ضمن حدود أمانة عمان لسنة 2024) ويعمل به من تاريخ نشره في الجريدة الرسمية.

##### المادة 2

| يكون للكلمات والعبارات التالية حيثما وردت في هذا النظام المعاني المخصصة لها أدناه مالم تدل القرينة على غير ذلك:-   |  |  |  | | --- | --- | --- | | الأمانة | : | أمانة عمان الكبرى. | | الأمين | : | أمين عمان أو رئيس لجنة الأمانة حسب مقتضى الحال. | | الدائرة | : | دائــرة ضبـــط نـاقــلات الأمراض ورعــــايـة الحيــــوان في الأمانة. | | ناقلات الأمراض | : | الحيوانات والحشرات التي تنقل  الأمراض الشائعة وتشمــل الفئران المنزليــة والجــرذان والصراصيـر والذباب والبعوض والكـلاب الضالــة التي تشكل خطراً على صحة الإنسان. | | الزواحف | : | لغايات هذا النظام يقصد بها الأفاعي فقط. | | الكلاب الضالة | : | كلاب موجودة خارج الموقع المرخص لها وليس في عنقها طوق أو أي وسيلة تعريفية معتمدة من الأمانة. | | الكلاب المسعورة | : | الكلاب التي تظهر عليـها علامـات داء الكلب. | | الكلاب العقورة | : | كلاب شرسة أو متوحشة والتي قد تهاجم أو تجرح  أي كائن حي. | | الأماكن العامة | : | مواقع ضمن حدود الأمانة تستخدم من عامـة الناس وتشمل الشوارع والمتنزهات والحدائق والمرافق العامة والتي قـد تعتبر أماكن لتواجد ناقلات الأمراض. | | مراكز الرعاية | : | هـي المواقـع التابعـة للأمانة والمخصصة لحجـز الكـلاب وحجرها. | |

##### المادة 3

أ- تقوم الدائرة بمكافحة ناقلات الأمراض ضمن حدود الأمانة وفق الأسس العلمية المعتمدة لهذه الغاية بمقتضى تعليمات يصدرها الأمين.
ب‌- تقوم الدائرة بمكافحة الكلاب الضالة بالطرق المعتمدة علمياً أما الكلاب العقورة أو الكلاب المسعورة فيتم قتلها.

##### المادة 4

|  |
| --- |
| للدائرة عمل خلطات الطعوم المستخدمة في مكافحة ناقلات الأمراض وتجهيزها وتغليفها ولها استيراد المواد التي تدخل في تصنيعها وفقا للتشريعات النافذة. |

##### المادة 5

|  |
| --- |
| للدائرة جمع وتصنيف ناقلات الأمراض بالتعاون مع الجامعات أو وزارة الصحة أو وزارة الزراعة وأي جهة أخرى ذات علاقة. |

##### المادة 6

|  |
| --- |
| للدائرة عمل حملات توعية للتعريف بناقلات الأمراض وطرق الوقاية منها. |

##### المادة 7

|  |
| --- |
| تلتزم الدائرة بتوفير الملابس وأدوات الصحة والسلامة العامة الخاصة للعاملين القائمين على مكافحة ناقلات الأمراض والزواحف لوقايتهم من أخطارها. |

##### المادة 8

|  |
| --- |
| تقوم الأمانة بتوفير المبيدات والمواد وأجهزة الرش والمعدات اللازمة لمكافحة ناقلات الأمراض والزواحف. |

##### المادة 9

|  |
| --- |
| تقوم الدائرة بمكافحة ناقلات الأمراض والزواحف في الأماكن العامة على مدار السنة، بما في ذلك أيام الجمع والأعياد والعطل الرسمية وفي الظروف الطارئة وكلما اقتضت الحاجة. |

##### المادة 10

|  |
| --- |
| تقوم الدائرة بمكافحة ناقلات الأمراض في المؤسسات الرسمية والعامة عند الطلب بموجب تعليمات يصدرها الأمين لهذه الغاية. |

##### المادة 11

|  |
| --- |
| تقوم الدائرة بزرع طعوم الزواحف عند الطلب في الأماكن العامة وبما لا يتعارض مع أحكام التشريعات النافذة. |

##### المادة 12

للأمانة وبالتنسيق مع أي من الجهات المختصة القيام بحملات مكافحة ناقلات الأمراض والزواحف، خارج حدود الأمانة.

##### المادة 13

يصدر الأمين التعليمات اللازمة لتنفيذ أحكام هذا النظام.
