# نظام البحث العلمي في جامعة الطفيلة التقنية

##### المادة 1

|  |
| --- |
| يسمى هذا النظام (نظام البحث العلمي في جامعة الطفيلة التقنية لسنة 2016 ) ويعمل به من تاريخ نشره في الجريدة الرسمية. |

##### المادة 2

|  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| يكون للكلمات التالية حيثما وردت في هذا النظـام المعـاني المخصصة لها أدناه ما لم تدل القرينة على غير ذلك:-       |  |  |  | | --- | --- | --- | | الجامعــة | : | جامعة الطفيلة التقنية. | | الرئيــس | : | رئيس الجامعة. | | العميـــد | : | عميد البحث العلمي في الجامعة. | |

##### المادة 3

|  |
| --- |
| يقصد بالبحث العلمي كل جهد علمي يهدف إلى تنمية المعرفة الإنسانية وتعمل الجامعة على تنظيم شؤونه ودعمه بمختلف الوسائل المادية والمعنوية والبشرية وفقا لأحكام هذا النظام . |

##### المادة 4

|  |
| --- |
| أ- يشكل في الجامعة مجلس يسمى (مجلس البحث العلمي) برئاسـة الرئيس وعضوية العميد نائباً للرئيس  و ثلاثة من أعضاء الهيئة التدريسية الأعلى رتبة  في الجامعة يختارهم مجلس العمداء لمدة سنتين قابلة للتجديد لمرة واحدة، على أن يراعى في ذلك تنوع التخصصات.  ب- لمجلس العمداء تعيين عضو إضافي أو أكثر في المجلس من خارج الجامعة من ذوي الخبرة وممن لهم صلة بالبحث العلمي لمدة سنة واحدة قابلة للتجديد لمرة واحدة. |

##### المادة 5

|  |
| --- |
| يتولى مجلس البحث العلمي  المهام والصلاحيات التالية:-  أ- اقتراح سياسة البحث العلمي في الجامعة وأولوياته ورفعها إلى مجلس العمداء لإقرارها.  ب-النظر في مشروعات البحوث العلمية وإقرارها.  ج- اقتراح الأسس الكفيلة بحفظ حقوق الجامعة وحقوق الباحثين فيما يتعلق بالبحوث العلمية التي تعدّ في الجامعة أو بمشاركتها أو بنتائج هذه البحوث ورفعها إلى مجلس العمداء لإقرارها.  د-  النظر في إجازة المخطوطات المؤلفة والمحققة والمترجمة بعد   تقييمها والتوصية لمجلس العمداء بدعم نشرها.  هـ- وضع أسس التعاون والتنسيق مع الجهات الأخرى المعنية بالبحث العلمي.  و- مناقشة مخصصات البحث العلمي لإدراجها في موازنة الجامعة.  ز- مناقشة التقرير السنوي لعمادة البحث العلمي  وأي أمور أخرى تتعلق بالبحث العلمي. |

##### المادة 6

|  |
| --- |
| أ- يجتمع مجلس البحث العلمي  بدعوة من رئيس المجلس أو نائبه عند غيابه ويكون اجتماعه قانونياً بحضور أغلبية أعضائه على أن يكون رئيس المجلس أو نائبه من بينهم ويتخذ قراراته بأغلبية أصوات أعضائه الحاضرين. |

**ب - يضع المجلس الأسس اللازمة لتنظيم اجتماعاته.**

##### المادة 7

|  |
| --- |
| للمجلس أن يمنح جوائز تقديرية أو تشـجيعية للبحوث العلمية القيمة وتقديم المساعدات لنشرها. |

##### المادة 8

|  |
| --- |
| يتولى العميد المسؤوليات التالية:-  أ-  تنفيذ سياسة البحث العلمي في الجامعة و تنظيم شؤونه ودعمه وتشجيعه.  ب- متابعة تنفيذ قرارات المجلس واقتراحاته.  ج- إعداد التقرير السنوي عن نشاطات البحث العلمي وتقديمه إلى المجلس.  د- السعي لإيجاد مصادر تمويل للبحث العلمي من داخل المملكة ومن خارجها.  هـ-  متابعة نشاطات البحث العلمي داخل الجامعة وخارجها . |

##### المادة 9

|  |
| --- |
| تعرض الأمور التي لم يرد عليها نص في هذا النظام على مجلس العمداء لاتخاذ القرار المناسب بشأنها وبما لا يتعارض مع أحكام هذا النظام. |

##### المادة 10

|  |
| --- |
| أ- يصدر مجلس العمداء التعليمات اللازمة لتنفيذ أحكام هذا النظام بما في ذلك تنظيم شؤون البحث العلمي في الجامعة وتشجيعه ودعمه ونشره ومتابعة تقييمه على أن تراعي التعليمات أخلاقيات البحث العلمي واعرافه |

**ب-  يستمر العمل بالتعليمات والقرارات الصادرة بموجب نظام البحث العلمي في جامعة الحسين بن طلال الى ان تلغى أو يستبدل غيرها بها وفقا لأحكام هذا النظام .**
