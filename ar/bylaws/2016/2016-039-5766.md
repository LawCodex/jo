# نظــام منح الدرجات والشهادات فـي جامعـة الطفيلــة التقنيــة

##### المادة 1

|  |
| --- |
| يسمى هذا النظام (نظام منح الدرجات والشهادات في جامعة الطفيلة التقنية لسنة 2016) ويعمل به من تاريخ نشره في الجريدة الرسمية . |

##### المادة 2

|  |  |  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| يكون للكلمات التالية حيثما وردت في هذا النظام المعاني المخصصة لها أدناه ما لم تدل القرينة على غير ذلك:-     |  |  |  | | --- | --- | --- | | الجامعــــة | : | جامعة الطفيلة التقنية. | | المجلــــس | : | مجلس عمداء الجامعــة. | | الكليـــــة | : | أي كلية في الجامعـــة. | | المركــــز | : | أي مركز علمي في الجامعة. | |

##### المادة 3

|  |
| --- |
| تمنح الجامعـة الدرجات والشهادات التالية:-      أ- الدرجة الجامعية الأولى ( البكالوريوس).  ب- شهادة الدبلوم العالي.  ج- الدرجة الجامعية الثانية ( الماجستيـر).  د- الدرجة الجامعية الثالثة ( الدكتـوراة).  هـ- درجة الدكتوراة الفخرية.  و- أي درجة علمية أو درجة فخرية أو شهادات أخرى يوافق عليها المجلس . |

##### المادة 4

|  |
| --- |
| أ- تحدد متطلبات وشروط منح الدرجات العلميـة والشهادات وحقول التخصص ذات العلاقة بها بمقتضى تعليمات يصدرها المجلس.    ب- تحـدد متطلبات وشروط منـح الدرجات الفخـرية بمقتضى تعليمات يصدرها المجلس. |

##### المادة 5

|  |
| --- |
| ‌أ- تمنح الدرجات من مستـوى الدرجة الجامعية الأولى (البكالوريوس) والشهـادات بقرار من المجلس بناءً على تنسيب من مجلس الكلية المختص أو مجلس المركز أو المعهد المختص في الجامعة.    ‌ب-تمنح الدرجات من مستوى الدرجة الجامعية الثانية (الماجستير) والدرجة الجامعية الثالثة (الدكتوراة) بقرار من المجلس بناء على تنسـيب من مجلس الدراسـات العليـا المستند إلى توصية مجلس الكلية.    ‌ج- تمنح الدرجات الفخرية بقرار من المجلس بناءً على تنسيب رئيس الجامعة. |

##### المادة 6

يستمر العمل بالتعليمات والقرارات الصادرة بموجب نظام منح الدرجات والشهادات في جامعة الحسين بن طلال الى ان تلغى أو يستبدل غيرها بها وفقا لأحكام هذا النظام .
