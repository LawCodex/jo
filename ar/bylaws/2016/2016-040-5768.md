# نظام المراكز العلمية في جامعة الطفيلة التقنية

##### المادة 1

|  |
| --- |
| يسمى هذا النظام (نظام المراكز العلمية في جامعة الطفيلة التقنية لسنة2016) ويعمل به من تاريخ نشره في الجريدة الرسمية. |

##### المادة 2

|  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| يكون للكلمات التالية  حيثما وردت في هذا النظام المعاني المخصصة لها أدناه ما لم تدل القرينة على غير ذلك:-     |  |  |  | | --- | --- | --- | | القانون | : | قانون الجامعات الأردنية. | | الجامعة | : | جامعة الطفيلة التقنية . | | الرئيس | : | رئيس الجامعة . | | المركز | : | أي مركز للتعليم والتدريب والاستشارات والخدمات  في الجامعة. | | المدير | : | مدير المركز. | | المجلس | : | مجلس المركز المشكل بمقتضى أحكام هذا النظام. | |

##### المادة 3

|  |
| --- |
| ينشأ في الجامعة بقرار من مجلس التعليم العالي بناء على تنسيب مجلس أمناء الجامعة مركز أو أكثر وفقاً لأحكام القانون يهدف الى تحقيق غايات علمية في مجالات البحث او التدريس او التدريب او التأهيل أو الاستشارات اوالخدمات أو أي برامج خاصة . |

##### المادة 4

|  |
| --- |
| أ-1- يشكل للمركز مجلس لا يزيد عدد اعضائه على احد عشر عضوا يعينهم الرئيس بعد الاستئناس برأي مجلس العمداء لمدة سنتين قابلة للتجديد.  2- يسمي الرئيس من بين أعضاء المجلس رئيسا له ونائباً للرئيس.    ب- يتولى ادارة المركز مدير يختاره الرئيس لمدة سنتين قابلة للتجديد  . |

##### المادة 5

|  |
| --- |
| يمارس المجلس الصلاحيات التي يمارسها مجلس الكلية واي صلاحيات أخرى لتحقيق اهدافه وفقا لأحكام القانون. |

##### المادة 6

|  |
| --- |
| يتولى المدير المهام و الصلاحيات التالية:-  أ- تنفيذ قرارات المجلس بما في ذلك تنفيذ برامج البحث والدراسة والمحاضرات والدورات .  ب- إدارة شؤون المركز الإدارية والمالية  وفقاً  لأحكام  التشريعات المعمول بها في الجامعة والتعليمات الصادرة عن مجلس العمداء.  ج- إعداد مشروع المخصصات السنوية اللازمة للمركز ورفعها  إلى المجلس لمناقشتها.  د- تقديم تقرير في نهاية كل سنة دراسية إلى الرئيس عن أعمال المركز وأنشطته وإنجازاته وأي اقتراحات يرى فيها مصلحة المركز.  هـ- أي مهام يكلفه الرئيس بها . |

##### المادة 7

|  |
| --- |
|  |

تتكون الموارد المالية للمركزمما يلي:

أ- المبالغ المخصصة للمركز في الموازنة السنوية للجامعة.

ب- الهبات والتبرعات والوصايا وريع الوقف والإعانات والمنح التي يتم قبولها وفق التشريعات المعمول بها.

**ج- نسبة من إيرادات البرامج التي ينظمها المركز يحدد مقدارها بتعليمات تصدر لهذه الغاية .**

##### المادة 8

تسري على العاملين في المركز انظمة الجامعة وتعليماتها.

##### المادة 9

يصدر مجلس العمداء بناء على تنسيب الرئيس التعليمات اللازمة لتنفيذ أحكام هذا النظام ، بما في ذلك تحديد الاهداف الخاصة بكل مركز وهيكله التنظيمي وسائر الأمور المتعلقة به .

##### المادة 10

|  |
| --- |
| أ- تعتبر المراكز المنشأة في الجامعة قبل نفاذ احكام هذا النظام وكأنها منشأة بمقتضاه وتسري عليها احكامه. |
| **ب- يستمر العمل بالتعليمات والقرارات الصادرة بموجب نظام المراكز العلمية في جامعة الحسين بن طلال الى ان تلغى أو يستبدل غيرها بها وفقا لاحكام هذا النظام.** |
