# نظام التنظيم الاداري لدائرة الجمارك / صادر بمقتضى المادة (120) من الدستور

##### المادة 1

يسمى هذا النظام ( نظام التنظيم الاداري لدائرة الجمارك لسنة 2011 ) ويعمل به من تاريخ نشره في الجريدة
الرسمية .

##### المادة 2

يكون للكلمات والعبارات التالية حيثما وردت في هذا النظام المعاني المخصصة لها ادناه ، ما لم تدل القرينة
على غير ذلك :-
الوزير:وزير المالية 0
الدائرة:دائرة الجمارك 0
المدير العام:مدير عام الدائرة 0
المديرية:أي مديرية في الدائرة 0
المركز الجمركي:أي مركز جمركي في الدائرة 0
اللجنة:لجنة التخطيط والتنسيق في الدائرة المشكلة بموجب احكام هذا النظام 0

##### المادة 3

أ- تهدف الدائرة الى تقديم خدمة جمركية متميزة تلبي متطلبات التنمية الاقتصادية وتواكب التطورات على
الصعيدين الوطني والعالمي من خلال تحقيق الاهداف التالية :-

1-المساهمة في رفع كفاءة الاقتصاد الوطني وتشجيع الاستثمار وتعزيز قدرة الصناعة الوطنية على المنافسة .

2-تسهيل حركة المسافرين والتبادل التجاري بين المملكة والدول الاخرى 0

3-المساهمة في الحد من الانشطة التجارية غير المشروعة .

4-رفد الخزينة بالايرادات .

ب-تعمل الدائرة على تحقيق اهدافها من خلال :-

1-تحديث العمليات والاجراءات الجمركية للمسافرين والبضائع وتبسيطها وتطويرها .

2-مراقبة حركة المسافرين ووسائط النقل العابرة لحدود المملكة وفقاً لصلاحيات الدائرة بمقتضى التشريعات
النافذة .

3-تحديث وتطوير وسائل مكافحة التهريب ودور الدائرة في مكافحة الانشطة التجارية غير المشروعة 0

4-تحديث البنية التحتية وتنمية الموارد البشرية وتطوير اساليب العمل الادارية والفنية .

##### المادة 4

يتكون الهيكل التنظيمي العام للدائرة على النحو التالي :-

أ- المدير العام 0

ب-مساعدو المدير العام 0

ج- مستشارو المدير العام 0

د- المديريات 0

هـ- المراكز الجمركية 0

و- المختبرات الجمركية 0

##### المادة 5

أ-يرتبط المدير العام بالوزير ، ويكون مسؤولاً عن تنفيذ مهام الدائرة و حسن سير العمل فيها 0

ب-يرتبط بالمدير العام كل من :

1-المساعد للشؤون الادارية والمالية .

2-المساعد للشؤون الفنية الجمركية 0

3-المساعد لشؤون الالتزام والتسهيل 0

4-المستشارين 0

5-مكتب المدير العام 0

6-المديريات التالية :
-النيابة العامة الجمركية .
-الرقابة والتفتيش 0
-مكافحة التهريب 0
-الاستراتيجيات والتطوير المؤسسي 0

7-المراكز الجمركية 0

##### المادة 6

أ- ترتبط بمساعد المدير العام للشؤون الادارية والمالية المديريات التالية :-

1-الموارد البشرية 0

2-التدريب الجمركي 0

3-الشؤون المالية 0

4-الشؤون الادارية 0

5-الابنية والصيانة 0

6-خدمة الجمهور والمتابعة 0

7-العلاقات العامة والاعلام والتعاون الدولي 0

ب- ترتبط بمساعد المدير العام للشؤون الفنية الجمركية المديريات التالية :-

1-التعريفة والاتفاقيات 0

2-الادخال المؤقت 0

3-الاعفاءات 0

4-شؤون القيمة 0

5-الترانزيت والتخليص 0

6-القضايا 0

7-الشؤون القانونية 0

8-المختبرات الجمركية 0

ج- ترتبط بمساعد المدير العام لشؤون الالتزام والتسهيل المديريات التالية :-

1-الجودة الجمركية الشاملة 0

2-ادارة المخاطر 0

3-الاستخبار الجمركي 0

4-الترفيق الجمركي 0

5-الاتصالات والسيطرة الالكترونية 0

6-تكنولوجيا المعلومات 0

##### المادة 7

أ- تشكل في الدائرة لجنة تسمى ( لجنة التخطيط والتنسيق ) برئاسة المدير العام وعضوية كل من :-

1-مساعدي المدير العام 0

2-مديري المديريات التالية :-
-الرقابة والتفتيش 0
-الاستراتيجيات والتطوير المؤسسي 0
-الموارد البشرية 0
-الشؤون المالية 0
-الشؤون القانونية 0
-الجودة الجمركية الشاملة 0
-تكنولوجيا المعلومات 0
-المديرية ذات العلاقة 0

3-اثنين من مديــري المراكز الجمركية يسميهما المدير العام 0

ب-يسمي المدير العام احد مساعديه نائباً لرئيس اللجنة 0

ج- تتولى اللجنة دراسة الامور التالية وتقديم التوصيات بشأنها:-

1-خطط وبرامج عمل الدائرة ومتابعة تنفيذها.

2-اداء الدائرة وانجازاتها والسبل الناجعة للنهوض بعملها بما يضمن تحقيق اهدافها على النحو الامثل.

3-الخطة العامة لبرامج التدريب لموظفي الدائرة.

4-مشروع الموازنة السنوية للدائرة وجدول تشكيلات الوظائف فيها.

5-مشروعات القوانين والانظمة والتعليمات المتعلقة بعمل الدائرة.

6-الهيكل التنظيمي للدائرة وارتباطات المديريات والمراكز الجمركية والاقسام وفقا لمتطلبات العمل.

7-أي امور اخرى يحيلها المدير العام اليها.

##### المادة 8

أ- تجتمع اللجنة بدعوة من رئيسها او نائبه مرة على الاقل كل ثلاثة اشهر وكلما دعت الحاجة ، ويكون اجتماعها
قانونياً بحضور أغلبية أعضائها على أن يكون الرئيس أو نائبه من بينهم ، وتتخذ توصياتها بأغلبية أصوات اعضائها ،
وفي حال تساوي الاصوات يرجح الجانب الذي صوت معه رئيس الاجتماع 0

ب - لرئيس اللجنة دعوة أي من المستشارين او أي من موظفي الدائرة او أي شخص من خارجها للمشاركة في
اجتماعات اللجنة للاستئناس برأيه في الامور المعروضة عليها دون ان يكون له حق التصويت 0

ج- يكون مدير مديرية الاستراتيجيات والتطوير المؤسسي أمين سر للجنة يتولى الإعداد لاجتماعاتها وتدوين
محاضرها وتنظيمها وحفظ القيود والمعاملات الخاصة بها ومتابعة تنفيذ توصياتها0

##### المادة 9

أ- لمجلس الوزراء بناء على تنسيب الوزير المستند الى توصية المدير العام احداث أي مديرية في الدائرة أو
دمجها في غيرها او الغاؤها 0

ب- للمدير العام بناء على تنسيب اللجنة احداث أي قسم في المديرية او المركز الجمركي او المختبر الجمركي
او دمجه في غيره او الغاؤه 0

##### المادة 10

يصدر الوزير بناء على تنسيب المدير العام التعليمات اللازمة لتنفيذ احكام هذا النظام بما في ذلك مايلي :-

أ-تحديد مهام المديريات والمختبرات الجمركية وواجباتها 0

ب-وصف الوظائف وتصنيفها في الدائرة 0

ج- تحديد الهيكل التنظيمي للمديريات والمراكز الجمركية 0

د- تحديد العلاقة واساليب الاتصال والتنسيق في الدائرة 0

##### المادة 11

يلغى نظام التنظيم الاداري لدائرة الجمارك رقم (43) لسنة 2000 0
