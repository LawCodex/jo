# نظام لوحات المركبات / صادر بمقتضى الفقرة (ج) من المادة (5) من قانون السير رقم (47) لسنة 2001

##### المادة 1

يسمى هذا النظام ( نظام لوحات المركبات لسنة 2003 ) ويعمل بــه من تاريخ نشره في الجريدة الرسمية.

##### المادة 2

تقسم لوحات المركبات الى الفئات التالية:-

أ-لوحات سيارات القصور الملكية وتكون ارضيتها بيضاء والاحرف والارقام فيها سوداء مع عبارة ( القصور الملكية ) باللغتين
العربية والانجليزية.

ب-لوحات سيارات رئيس الوزراء والوزراء وتكون ارضيتها بيضاء والاحرف والارقام فيها حمراء مع كلمة ( حكومة ) باللغتين
العربية والانجليزية.

ج-1- لوحة سيارة كل من رئيس مجلس الاعيان ورئيس مجلس النواب وتكون ارضيتها بيضاء والاحرف والارقام فيها حمراء وباللغة
العربية عبارة ( مجلس الاعيان ) او ( مجلس النواب ) حسب مقتضى الحال مع الرقم (1) والاحرف ( PAR ) باللغة الانجليزية.

2- لوحة سيارة رئيس المجلس القضائي وتكون ارضيتها بيضاء والاحرف والارقام فيها حمراء وباللغة العربية عبارة ( المجلس
القضائي ) مع الرقم (1) و الحرفين ( J.C ) باللغة الانجليزية.

د-1- لوحة سيارة كل من عضو مجلس الاعيان وعضو مجلس النواب وتكون ارضيتها بيضاء والاحرف والارقام فيها حمراء وباللغة
العربية عبارة ( مجلس الاعيان ) او (مجلس النواب ) مع الرقم المتسلسل الذي يخصص للوحة من قبل المجلس المختص ابتداء
من الرقم (2) والاحرف ( PAR ) باللغة الانجليزية وتصرف لسيارة مرخصة واحدة.

2-لوحة سيارة عضو المجلس القضائي وتكون ارضيتها بيضاء والاحرف والارقام فيها حمراء وباللغة العربية عبارة ( المجلس
القضائي ) مع الرقم المتسلسل الذي يخصص للوحة من قبل المجلس ابتداء من الرقم (2) والحرفين ( J. C ) باللغة الانجليزية
وتصرف لسيارة مرخصة واحدة.

هـ- لوحات المركبات العائدة للوزارات والدوائر الحكومية والمؤسسات الرسمية العامة والبلديات و/او لوحات المركبات المستأجرة
لمنفعة أي منها طيلة مدة عقد الاستئجار او طيلة مدة نفاذ العقد وتكون ارضيتها حمراء والاحرف والارقام فيها بيضاء مع
كلمة ( الاردن ) باللغتين العربية والانجليزية.

و-لوحات سيارات الهيئات الدبلوماسية والقنصلية وتكون بأرضية ذات لونين:
الابيض والاصفر والاحرف والارقام فيها سوداء مع الحرفين ( هـ 0 د ) الدالين على الهيئات الدبلوماسية والحرفين ( هـ
0 ق ) الدالين على الهيئات القنصلية بالاضافة لكلمة ( الاردن ) باللغتين العربية والانجليزية.

ز-لوحات سيارات الهيئات الدولية والجمعيات الخيرية المعفاة من الرسوم بموجب الاتفاقيات الدولية او التشريعات المحلية
ولوحات السيارات المسجلة باسم الجامعات الاردنية الرسمية والجمعية العلمية الملكية وتكون ارضيتها زرقاء والاحرف والارقام
فيها بيضاء مع كلمة ( الاردن ) باللغتين العربية والانجليزية.

ح-لوحات سيارات المراسم وتكون ارضيتها بيضاء والاحرف والارقام فيها حمراء مع كلمة ( مراسم ) ورقم اللوحة باللغة العربية.

ط-لوحات المركبات العائدة لسلطة منطقة العقبة الاقتصادية الخاصة وتكون ارضيتها بيضاء والاحرف والارقام فيها حمراء
مع عبارة ( سلطة العقبة ) باللغة العربية وكلمة ( AQABA ) باللغة الانجليزية وشعار السلطة.

ي-لوحات السيارات الخصوصية وتكون ارضيتها بيضاء والاحرف والارقام فيها سوداء مع كلمة ( الاردن ) باللغتين العربية
والانجليزية.

ك-لوحات السيارات العمومية تكون ارضيتها خضراء والاحرف والارقام فيها بيضاء مع كلمة ( الاردن ) باللغتين العربية والانجليزية.

ل-لوحات مركبات الاشغال الانشائية والزراعية وتكون ارضيتها سوداء والاحرف والارقام فيها بيضاء مع عبارة (انشائي CONST
) للمركبات الانشائية و ( زراعي AGR ) للمركبات الزراعيـة وباللغتين العربية والانجليزية في كل من اللوحتين.

م-لوحات مركبات الادخال المؤقت وتكون ارضيتها صفراء والاحرف والارقام فيها سوداء مع كلمة ( الاردن ) باللغتين العربية
والانجليزية.

ن-لوحات الدراجات الآلية وتكون ارضيتها بيضاء والاحرف والارقام فيها سوداء مع كلمة ( الاردن ) باللغتين العربية والانجليزية.

س-لوحات سيارات التأجير وتكون ارضيتها خضراء والاحرف والارقـام فيها صفراء مع كلمة ( الاردن ) باللغتين العربية والانجليزية.

ع-لوحات سيارات الادخال الجمركي والتي تدخل مراكز الحدود بدون لوحات من بلدها والسيارات الاجنبية التي تمدد اقامتها
لمدة تزيد على ثلاثة اشهر وتكون ارضيتها سوداء والاحرف والارقام فيها بيضاء مع عبارة تتضمن اسم مركز الحدود الذي دخلت
منه بالاضافة لسنة صدورها وتنظم قيودها وفقا للتعليمات الخاصة بها.

ف-لوحات مركبات العبور بالترانزيت للمركبات التي تدخل مراكز الحدود بدون لوحات ويقودها السائق لاخراجها من مراكز اخرى
على حدود المملكة او لادخالها الى المناطق الحرة او لمستودعات المستورد وتصرف هذه اللوحات للمركبات التي يتم تصنيعها
او تجميعها محليا وذلك عند تحويلها الى أي من مراكز الحدود او المناطق الحرة او المستودعات وتكون ارضيتها زرقاء والاحرف
والارقام فيها صفراء مع عبارة تتضمن كلمة ( ترانزيت ) واسم مركز الحدود الذي دخلت منه 0 بالاضافة لسنة صدورها وتنظم
اجراءات اصدارها وقيودها وفقا للتعليمات الخاصة بها.

ص-لوحات المركبات المخزنة في مستودعات الوكلاء التجاريين للمركبات او المزاولين لمهنة تجارتها المرخصين بذلك وتكون
ارضيتها صفراء والاحرف والارقام فيها سوداء مع كلمة ( مؤقت ) باللغة العربية والاحرف ( TEMP ) باللغة الانجليزية
وتنظم اجراءات اصدارها وقيودها ومدتها وفقا للتعليمات التي يصدرها وزير الداخلية لهذه الغاية.

ق-لوحات المركبات التي يتم تصنيعها محليا من قبل المصانع المرخصة بذلك وتكون ارضيتها صفراء والاحرف والارقام فيها
ســوداء مع كلمـة ( تجربة ) باللغـة العربيـة وكلمة ( TEST ) باللغة الانجليزية.

ر-لوحات المقطورات وانصاف المقطورات وتكون ارضيتها صفراء والاحرف والارقام فيها حمراء مع كلمة ( مقطورة ) باللغة العربية
و الاحرف ( TRL ) باللغة الانجليزية.

ش-لوحات مركبات الادخال المؤقت المصروفة وفقا لنظام الادخال المؤقت للمركبات لمنطقة العقبة الاقتصادية الخاصة وتكون
ارضيتها صفراء والاحرف والارقام فيها سوداء مع عبارة ( العقبة الخاصة ) باللغة العربية والاحرف ( ASEZ ) باللغة الانجليزية
مع وضع لاصق يحمل شعار السلطة باللون الازرق والاخضر غير قابل للنزع.

##### المادة 3

يجوز لامانة عمان الكبرى والبلديات او الهيئات التي تقوم مقامها اصدار اللوحات المبينة تاليا مع كتابة اسم الجهة التي
اصدرتها على ان تحتفظ كل جهة بسجل خاص باللوحات التي تصدرها على ان تكون ارضيتها بيضاء والاحرف والارقام فيها سوداء:-

أ-لوحات الدراجات الهوائية التي تسـير بقوة دافعة من راكبها.

ب-لوحات العربات التي تجرها الحيوانات او تجر او تدفع باليد.

##### المادة 4

تتولى ادارة الترخيص تنظيم او اعادة تنظيم فئات لوحات المركبات بتسلسل خاص لكل منها على ان تبقى جميع العقود المتعلقة
بالمركبات والحقوق المترتبة عليها او لاصحابها والارقام المحتفظ بها وذلك وفقا للتسلسل الجديد الذي يتم تنظيمه بمقتضى
هذا النظام ، سارية المفعول الى المدى الذي كانت عليه بموجب الارقام الاساسية للمركبات.

##### المادة 5

تصنع جميع لوحات المركبات من قبل ادارة الترخيص ولا يجوز لاي جهة اخرى القيام بذلك ويتم تصنيعها بطريق الضغط النافر
باستثناء اللوحات المنصوص عليها في المادة (3) من هذا النظام وتكون على الاشكال الثلاثة التالية لتتناسب مع مختلف
انواع المركبات:-

أ-الشكل الاول: ويكون طول اللوحة فيه (432ملم) وعرضها (115ملم).

ب-الشكل الثاني: ويكون طول اللوحة فيه (345ملم) وعرضها (165ملم).

ج-الشكل الثالث: ويكون طول اللوحة فيه (240ملم) وعرضها (135ملم).

##### المادة 6

تكون المساحة التي تشغلها الارقام في اللوحة كما يلي:-

أ-(72 X 32ملم) للارقام العربية في لوحات الشكلين الاول والثاني باستثناء سيارات القصور الملكية.

ب-(40 X 25ملم) للارقام الانجليزية في لوحات الشكل الاول باستثناء لوحات سيارات المراسم وسيــارات العبور ( الترانزيت
) وسيارات الادخال الجمركي.

ج-(50 X 30ملم) للارقام الانجليزية في لوحات الشكل الثاني باستثناء لوحات سيارات القصور الملكية وسيارات المراسم وسيارات
العبور ( الترانزيت ) وسيارات الادخال الجمركي.

د-(55 X 35ملم) للارقام العربية المخصصة للوحات سيارات القصور الملكية وسيارات الهيئات الدبلوماسية والقنصلية وسيارات
الادخال الجمركي وسيارات العبور (الترانزيت) وللوحات الدراجات الآلية ذات الشكل الثاني.

هـ- (42 X 20ملم) للارقام العربية المخصصة للوحات سيارات القصور الملكية وسيارات الهيئات الدبلوماسية والقنصلية وسيارات
الادخال الجمركي وسيارات العبور ( الترانزيت ) ذات الشكل الاول.

و- (72 X 32ملم) للارقام الانجليزية المخصصة للوحات سيارات الهيئات الدبلوماسية ذات الشكل الاول.ز- (45 X 24ملم) لكل
من الارقام العربية والانجليزية المخصصة للمركبات العائدة لسلطة منطقة العقبة الاقتصادية الخاصة.

ح- (45 X 24ملم) لكل من الارقام العربية والانجليزية المخصصة لمركبات الادخال المؤقت لسلطة منطقة العقبة الاقتصادية
الخاصة.

##### المادة 7

تكون المساحة التي تشغلها العبارات والكلمات والاحرف في اللوحة كما يلي:-

أ-(90 X 35ملم) لكل من كلمة (الاردن) باللغتين العربية والانجليزية.

ب-(50 X 35ملم) لاحرف (هـ 0 د) او (هـ0 ق) باللغة العربية و ( C. D ) او ( C. C ) باللغة الانجليزية.

ج-(180 X 35ملم) لعبــارة ( القصور الملكية ) باللغتين العربية والانجليزية.

د-(90 X 35ملم) لعبارة ( مجلس الاعيان ) او ( مجلس النواب ) حسب مقتضى الحال باللغـة العربية و (PAR ) باللغة الانجليزية.

هـ- (90 X 35ملم) لكلمـة ( حكومـة ) باللغــة العربية و ( GOV ) باللغة الانجليزية.

و-(90 X 35ملم) لعبارة ( المجلس القضائي ) باللغة العربية و (50 X 35ملم) لكل من حرفي ( J. C ) في لوحة ارقام المجلس
القضائي.

ز-(90 X 35ملم) لكلمة (زراعي) او (انشائي) باللغة العربية و ( AGR ) او ( CONSTR ) باللغة الانجليزية.

ح-(90 X 35ملم) لكلمة (جمرك) او ( ترانزيت ) او اسم الجمرك الذي تصدر اللوحة عنه.

ط-(135 X 40ملم) لكلمة (مراسم).

ي-(90 X 35ملم ) لكلمة (مقطورة) باللغة العربية و (50 X 30ملم) و (TRL ) باللغة الانجليزية.

ك- (120 X 32ملم) لعبارة ( سلطة العقبة ) باللغة العربية ، و (90 X 25ملم) لكلمة ( AQABA ) باللغة الانجليزية ، و(35
X 35ملم) لشعار سلطة منطقة العقبة الاقتصادية الخاصة.

ل-(120 X32ملم) لعبارة ( العقبة الخاصة ) باللغة العربية ، و (90 X 25ملم) لكلمة ( ASEZ ) باللغة الانجليزية ، و (35
X 35ملم) لشعار سلطة منطقة العقبة الاقتصادية الخاصة.

م-(90 X 35ملم) لكلمة ( مؤقت ) باللغة العربية ، و ( TEMP ) باللغة الانجليزية.

ن-(90 X 35ملم) لكلمة ( تجربة ) باللغة العربية ، وكلمة ( TEST ) باللغة الانجليزية.

##### المادة 8

أ- يستوفى دينار واحد ثمنا لكل لوحة ارقام من لوحتي المركبة المصروفة لاول مرة او بدلا عن اللوحة التالفة وثلاثة دنانير
عن كل لوحة مفقودة.

ب- يعفى من الثمن المنصوص عليه في الفقرة (أ) من هذه المادة لوحات سيارات القصور الملكية وسيارات رئيس الوزراء ورئيسي
مجلسي الاعيان والنواب ورئيس المجلس القضائي والوزراء ولوحات سيارات الاعيان والنواب واعضاء المجلس القضائي ولوحات
السيارات الحكومية والبلدية ولوحات (المراسم) ولوحات العبور ( الترانزيت ) وتتحمل وزارة المالية تكاليف صنع هذه اللوحات
المعفاة من الثمن.

##### المادة 9

يلغى ( نظام لوحات المركبات رقم (57) لسنة 1989 ) وتعديلاته.
