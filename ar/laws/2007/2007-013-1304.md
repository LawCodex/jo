# قانون اللجنة الاولمبية

##### المادة1- يسمى هذا القانون ( قانون اللجنة الاولمبية الاردنية لسنة 2007 ) ويعمل به من تاريخ نشره في الجريدة الرسمية 0

##### المادة2- يكون للكلمات التالية حيثما وردت في هذا القانون المعاني المخصصة لها ادناه ما لم تدل القرينة على غير ذلك

اللجنة:اللجنــة الاولمبية الاردنية المنشأة بموجب احكام هذا القانون 0
الجمعية:الجمعية العامة للجنة 0
المجلس:مجلس ادارة اللجنة 0
الرئيس:رئيس اللجنة / رئيس المجلس 0
الاتحاد:الاتحاد الرياضي او النوعي الذي يشكل بمقتضى النظام الصادر استناداً لاحكام هذا القانون 0

##### المادة3- تنشأ في المملكة لجنة اهلية تسمى ( اللجنة الاولمبية الاردنية ) ذات شخصية اعتبارية واستقلال مالي

واداري ومركزها عمان تهدف الى رعاية الحركة الرياضية الاردنية بما يتفق مع المبادئ الاساسية للميثاق
الاولمبي وقرارات اللجنة الاولمبية الدولية 0

##### المادة4- تتولى اللجنة لتحقيق اهدافها المهام التالية

?أ-رعاية وتطوير الرياضة على الصعيد الوطني 0
?ب-تكريس مبدأ الخلق والقيم العربية والاسلامية والروح الرياضية ومكافحة المنشطات 0
?ج-المشاركة الفعلية في الانشطة التي تهدف الى ما يلي :-

1-تحقيق الوئام الانساني ومحاربة التمييز 0

2-تشجيع رياضة المرأة والترويج لها 0

3-الاهتمام بشؤون البيئة 0

##### المادة5- تحدد بمقتضى نظام يصدر لهذه الغاية ، الاحكام والاجراءات المتعلقة بتشكيل اللجنة وجمعيتها وشروط

العضوية فيها وتأليف مجلس ادارتها وعقد اجتماعاتهما وسائر امورهما الادارية والمالية والفنية بما في ذلك البدل
الذي تتقاضاه اللجنة مقابل الخدمات التي تقدمها 0

##### المادة6- تتكون الموارد المالية للجنة مما يلي

?أ-الدعم الذي تقدمه أي جهة حكومية او المخصصات التي ترصد للجنة في الموازنة العامة 0
?ب-المبالغ المقررة من الصندوق الوطني لدعم الحركة الشبابية والرياضية 0
?ج-الهبات والتبرعات التي تقدم من أي جهة على ان تؤخذ موافقة مجلس الوزراء عليها اذا كانت من مصدر غير اردني 0
?د-الدعم والمخصصات التي تقدمها اللجنة الاولمبية الدولية واتحاد اللجان الاولمبية الوطنية والهيئات التابعة لها
والمجلس الاولمبي الآسيوي ولجنة التضامن الاولمبي او أي هيئة رياضية معترف بها دولياً 0

هـ-عوائد استثمار اموال اللجنة المنقولة وغير المنقولة 0

##### المادة7- تمارس الجمعية الصلاحيات التالية

?أ-رسم السياسة العامة للجنة ووضع الخطط والبرامج اللازمة لتنفيذها بما في ذلك رعاية رياضة الهواية وتنظيم الاحتراف 0
?ب-انتخاب اعضاء المجلس 0
?ج-اقرار مشروع الموازنة السنوية للجنة والحساب الختامي 0

##### المادة8- يمارس المجلس الصلاحيات التالية

?أ-تنفيذ قرارات الجمعية 0
?ب-انشاء المعاهد او الاكاديميات او المتاحف الاولمبية 0
?ج-عقد المؤتمرات والندوات والدورات اللازمة لاعداد القيادات الرياضية وتأهيلها 0
?د-رعاية الرياضيين المتميزين والموهوبين لتطوير قدراتهم ومواهبهم 0

هـ-تمثيل المملكة لدى الجهات والهيئات ذات العلاقة بالحركة الاولمبية وتنظيم التبادل الرياضي وتوقيع
الاتفاقيات معها داخل المملكة وخارجها 0

و-الموافقة على تشكيل الاتحادات والاشراف عليها ومتابعة انشطتها ودعمها وتقديم الخبرات الفنية اللازمة لها 0

##### المادة9-أ- يتمتع الاتحاد بعد تشكيله بشخصية اعتبارية ذات استقلال مالي واداري ويتولى بهذه الصفة ممارسة

انشطته المختلفة وفقاً لاحكام هذا القانون والانظمة الصادرة بمقتضاه والتعليمات الاولمبية الدولية المتعلقة بأنشطتها 0

ب- تحدد بمقتضى نظام يصدر لهذه الغاية ، الاحكام والاجراءات المتعلقة بتشكيل الاتحادات وطريقة ادارتها
وحلها وتنظيم اجتماعاتها وسائر الامور الادارية والمالية المتعلقة بها 0

ج- تخضع موازنة هذه اللجنة واي اتحاد تابع لها لرقابة ديوان المحاسبة 0

##### المادة10- تحل اللجنة ، التي سيتم تشكيلها بمقتضى احكام النظام الصادر بالاستناد لاحكام هذا القانون ، محل

اللجنة الاولمبية المشكلة بموجب نظام اللجنة الاولمبية رقم (18) لسنة 1987 وتعديلاته وتعتبر الخلف القانوني
والواقعي لها وتؤول اليها جميع موجوداتها وحقوقها واموالها المنقولة وغير المنقولة وتتحمل جميع الالتزامات
المترتبة عليها وينقل اليها جميع موظفيها ومستخدميها وتعتبر خدماتهم فيها استمراراً لخدماتهم السابقة في تلك اللجنة 0

##### المادة11- يصدر مجلس الوزراء الانظمة اللازمة لتنفيذ احكام هذا القانون 0

##### المادة12- رئيس الوزراء والوزراء مكلفون بتنفيذ احكام هذا القانون 0
