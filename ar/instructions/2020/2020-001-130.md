# تعليمات اللجنة الملكية لإعمار مقامات الأنبياء والصحابة وإدارتها

##### المادة 1

|  |
| --- |
| تسمى هذه التعليمات ]تعليمات اللجنة الملكية لإعمار مقامات الأنبياء والصحابة وإدارتها لسنة 2020[ ويعمل بها من تاريخ نشرها بالجريدة الرسمية . |

##### المادة 2

|  |  |
| --- | --- |
| يكون للكلمات والعبارات الواردة في هذه التعليمات المعاني المخصصة لها أدناه ما لم تدل القرينة على خلاف ذلك: | |
| اللجنة الملكية لإعمار مقامات الأنبياء والصحابة وإدارتها المشكلة بمقتضى الرسالة الملكية السامية الموجهة لدولة رئيس الوزراء والصادرة برقم (17/29/1399) تاريخ  23/8/1992م |  |
| رئيس اللجنة . |  |
| وزارة الاوقاف والشؤون والمقدسات الاسلامية. |  |
| وزير الاوقاف والشؤون والمقدسات الاسلامية. |  |
| أمين عام الوزارة. |  |
| مديرية إعمار مقامات الأنبياء والصحابة وإدارتها في الوزارة . |  |
| مدير المديرية . |  |
| اللجنة التي تشكلها اللجنة الملكية لتتولى الأمور الفنية والخدمات المتعلقة بأبنية المقامات والمساجد الملحقة بها والإشراف على العاملين فيها. |  |
| رئيس القسم المالي في المديرية أو من تكلفه اللجنة محاسباً لها . |  |

##### المادة 3

|  |  |
| --- | --- |
| تتولى اللجنة تحقيق الأهداف المبينة في الرسالة الملكية السامية وعلى الأخص ما يلي :- | |
| إعمار وترميم وصيانة وتطوير مقامات الأنبياء والصحابة والمساجد التابعة لها الكائنة على ثرى الأردن. |  |
| أي أعمال أخرى تقرر اللجنة القيام بها تحقيقاً للرسالة الملكية السامية . |  |

##### المادة 4

|  |  |
| --- | --- |
| تتكون الموارد المالية للجنة من: | |
| أ- ما يخصص من الموازنة العامة . |  |
| ب- الهبات والتبرعات. |  |
| ج- ما يوقف لتحقيق أهداف اللجنة. |  |
| د- أي موارد أخرى توافق عليها اللجنة . |  |

##### المادة 5

ينشأ لدى الوزارة حساب بنكي أو أكثر باسم اللجنة تودع فيه موارد اللجنة ويصرف منه على تنفيذ غايات وأهداف اللجنة وفق أحكام هذه التعليمات.

##### المادة 6

تعقد اللجنة اجتماعات دورية بدعوة من رئيسها أو كلما دعت الحاجة ويكون اجتماعها قانونياً إذا حضره نصف الأعضاء بمن فيهم الرئيس وفي حال غياب الرئيس يحل محله
نائب الرئيس .

##### المادة 7

|  |  |  |
| --- | --- | --- |
|  | أ- | تصرف أموال اللجنة في تحقيق الغايات المبينة في المادة 3 من هذه التعليمات ووفق ما تتخذه اللجنة من قرارات . |
|  | ب- | يتولى محاسب اللجنة تنظيم مستندات الصرف والتحاويل المالية مع مراعاة الالتزام بأحكام النظام المالي المعمول به والتعليمات الصادرة بموجبه. |

##### المادة 8

|  |  |
| --- | --- |
| تنفذ الأشغال والخدمات الفنية الواردة في أهداف اللجنة بإحدى الطرق التالية: | |
| أ- العطاءات العامة. |  |
| ب- استدراج عروض بتوجيه دعوات خاصة. |  |
| ج- التلزيم. |  |
| د- التنفيذ المباشر. |  |

##### المادة 9

تراعى القواعد المنصوص عليها في نظام الأشغال واللوازم لوزارة الأوقاف والشؤون والمقدسات الإسلامية المعمول به والتعليمات الصادرة بموجبه.

##### المادة 10

تعتمد جداول تصنيف مقاولي الإنشاءات الصادرة عن وزارة الأشغال العامة والاسكان في جميع أشغال اللجنة .

##### المادة 11

توقع الاتفاقيات والعقود والمراسلات المتعلقة بأعمال اللجنة من الوزير ويمثلها لدى الجهات الأخرى .

##### المادة 12

أ- للوزير التعاقد مع المستشارين أو مدققي الحسابات وفق القوانين والأنظمة المعمول بها.

ب- تتولى إدارة قضايا الدولة تمثيل اللجنة في الدعاوى التي تقيمها اللجنة أو تقام عليها.

##### المادة 13

|  |  |  |
| --- | --- | --- |
|  | أ- | للجنة تشكيل اللجنة الفنية ولجنة مشتريات ولجنة عطاءات من أعضائها و/أو من غيرهم وتكليفها بطرح العطاءات وفتحها والتنسيب إلى الوزير لإحالتها. |
|  | ب- | للجنة تشكيل أي لجان أخرى من أعضائها و/أو من غيرهم، ولها أن تحدد مهامها  لغايات تحقيق أهداف اللجنة . |
|  | جـ- | للجنة تفويض الوزير  بأي من صلاحياتها على أن يكون التفويض خطياً ومحدداً. |

##### المادة 14

تتولى المديرية تنفيذ ومتابعة قرارات اللجنة وفقاً للتشريعات المعمول بها ، وبإسناد من أجهزة الوزارة .

##### المادة 15

تعتمد اللجنة دليل الوصف الوظيفي والمهام والواجبات للعاملين في المديرية واللجان الأخرى التي تشكلها اللجنة .

##### المادة 16

|  |  |
| --- | --- |
|  | تلغى التعليمات رقم (3) لسنة 1994 وما طرأ عليها من تعديلات. |
